# Format

([name], [age appearance], [race or ethnicity if human] [male/female], [body, height, skin, hair style, hair color, eye color, and any other physical traits], [clothing, accessories, color], [condition, pose, action, expression]).
[background details, objects, props (never characters)], [lighting, time of day (dawn/morning/afternoon/evening/night/etc), shot, composition].

# Prompt Rules

Generate Visual Prompt of the scene, no brackets.
Focus on most prominent character.
Only include footwear in the `clothing` if the scene makes footwear relevant to the image.
use visually descriptive language.

If in a sex scene:
make sure the prompt captures the act/scene in details.
use parentheses to emphasize the sex scene.
add details like sweating, glistening, dripping, wet, cum, etc.
example (user for reference only, write your own):
- `performing blowjob, (penis in mouth), dripping saliva`
- `having sex, missionary position, (penis in vagina), thrusting, sweating`
- `being fucked from behind, bent over, (penis in vagina)`
adjust sex position and pose according to the narrative.
